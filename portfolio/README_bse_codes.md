# bse_code column

BSE scrip code = the 6-digit number in the company's bseindia.com URL (e.g. https://www.bseindia.com/stock-share-price/titan-company-ltd/titan/500114/ -> 500114).
Filled from memory for the 30 names; the filings source checks the exchange's own company name against ours before using any announcement, so a wrong code feeds nothing (and says so in the run log). Verify any name whose log says 'no filings'.
